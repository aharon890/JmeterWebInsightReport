Place a new assert on the chart

+ Assert from chart, click a level — the editor opens seeded with that value. In phase 2 the rule still gates the run aggregate (green line), not each bucket; the chart makes that distinction visible instead of hiding it. Clicking a series point seeds that sampler + metric the same way.

Phase 3 — the time axis becomes assertable

Server metrics (CPU, lag, heap) are pure time series — chart-drag becomes their primary authoring surface, and an over clause folds the series into the judged scalar:

"target": { "source": "prometheus",
  "metric": "container_cpu_usage_seconds" },
"fail": { "gt": 85 },
"over": { "sustainedFor": "60s" }
