# Contract: the page's words per tool (decision 7)

One table in the template's context decides every label below. A JMeter run keeps today's words exactly (FR-006,
SC-001).

| Where | JMeter run (today) | k6 run |
|---|---|---|
| Header, after the title | `JMeter <version>` | `k6 <version>` |
| Samplers tab and its filter row | Samplers | Requests |
| Summary tile | Max Threads | Max VUs |
| Samplers table's thread column, Errors tab | Thread | VU |
| Transaction rows, the "Show transaction details" switch | Transaction | Group |
| Transaction help text ("JMeter counts a transaction run three ways") | as today | "A group pass is a transaction: its time is the sum of its requests', as JMeter's Transaction Controller counts it." |
| Footer | Generated by JMeter Web Insight Suite | as today (the product's name, exception 1) |
| Numbers note | as today | "Numbers follow JMeter's Aggregate Report rules." (exception 2) |
| Tool's own tab | none | named after `tool.name` (`k6`): thresholds, checks, group wall time, the six timing parts per request name, iterations, dropped iterations. Its statistics columns are k6's own summary columns (avg, min, med, max, p(90), p(95)), computed by the engine's exact aggregator. |
| A measure the tool doesn't give | n/a | "not measured" |

This table lists the places that decide the words. Every other occurrence in `report.html` and `report.js` (for
example "Max Active Threads", the Asserts editor's "sampler" texts) is listed by the inventory task (tasks.md T050) and
added here before the words change. Gatling later adds a column to this table, with no other change.
